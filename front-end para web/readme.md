
# 📚 Front-End para Web

Este repositório reúne as atividades, projetos e trabalhos desenvolvidos durante a disciplina de **Front-End para Web**, do curso de Engenharia de Software.

A disciplina tem como objetivo desenvolver conhecimentos e habilidades relacionados à criação de interfaces web, utilizando tecnologias fundamentais do desenvolvimento Front-End.

## 💻 Projeto desenvolvido

### Portfólio Pessoal

Como parte das atividades da disciplina, foi desenvolvido um portfólio pessoal com o objetivo de apresentar informações profissionais, conhecimentos técnicos, habilidades e projetos.

**Tecnologias utilizadas:**
- HTML5
- CSS3
- JavaScript

O projeto foi desenvolvido aplicando conceitos de estruturação, estilização, responsividade e interatividade em páginas web.

## 🎯 Objetivos da disciplina

- Compreender os fundamentos do desenvolvimento Front-End.
- Aplicar HTML, CSS e JavaScript na construção de páginas web.
- Desenvolver interfaces organizadas, funcionais e responsivas.
- Aprimorar habilidades práticas de desenvolvimento web.
- Construir projetos que contribuam para o portfólio acadêmico e profissional.
